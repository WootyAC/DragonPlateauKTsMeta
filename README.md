This meta will navigate your character to the Dragon Plateau, flag with the NPCs, and begin killing the various monsters for the kill tasks.

Using The Meta

Install the meta by moving the DragonPlateau_Wooty.met and DragonPlatHunting.nav file to your Virindi Tank directory

The included DragonPlatHunting.nav file is a basic linear nav route. You can edit this nav route based on whatever route you wish to hunt, but the nav route should start somewhere close to 65.8N 82.5E. This is to avoid dragging monsters to the lifestone and near the NPCs. Since a character dying while already in a meta's 'Dead' state can cause issues with their meta, please do your best to avoid having your nav route go too close to the lifestone. 


You can start the meta from anywhere. The meta will navigate you to the Dragon Plateau. 
 -When the meta begins, it will begin by casting LS Sending (unless you are already at the Dragon Plateau). If you are not LS'd at the Dragon Plateau, it will cast Lifestone Recall. If you are neither lifestoned, nor lifestone tied, to the Dragon Plateau lifestone, it will navigate you to the Dragon Plateau through the Rossu Morta Chapterhouse in Haven. Part of this is for the meta to "learn" the quickest route back to the Dragon Plateau for your character. For instance, if your character is lifestoned at the Dragon Plateau, it will simply resume right away. If your character is lifestone tied, it will lifestone recall to get back. If neither, it will navigate through haven every time. 

You can lifestone anywhere, but since most characters die a lot at the Dragon Plateau at this point in the game, it is STRONGLY recommended that you lifestone at the Dragon Plateau. 

The meta will talk to Carmen every time before it heads out. You do not need to (and should not) have a trip to Carmen in your DragonPlatHunting.nav file if you choose to edit it. 

Make sure your character isn't "busy" (fighting monsters etc) when you start the meta

The meta will flag you, and turn in the KTs to the NPC when complete.
 -You do NOT have to wait for your kill task timer to be up before you begin the meta. It will periodically check if your timer is up, and when it is, it will navigate back to the NPCs and flag you. 

 When the kill tasks are complete, it will simply resume hunting. 

Avoid starting the meta if you are close to your luminance cap so you don't waste any luminance
